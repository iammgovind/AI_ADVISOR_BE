# FI Module Scope Index

This section summarizes the project by business capability and corresponding backend modules.

## Core modules
- Auth and access control
- User management
- Expense tracking
- Budget planning
- Goal tracking
- Investment tracking
- Dashboard analytics
- RAG / document intelligence
- Financial advisory agents

## Business story
FI is a personal finance backend that turns raw financial data into an actionable system for tracking spending, managing budgets, planning goals, and making better investment decisions.

## Module map
- Auth: account creation, login, JWT, refresh flow
- Users: profile and administration
- Expenses: daily spending and category tracking
- Budgets: monthly category caps and alerts
- Goals: target-based saving plans
- Investments: holdings and portfolio health
- Dashboard: summary analytics and trend reporting
- RAG: upload and ask questions about PDFs
- Financial agents: risk, savings, and multi-agent recommendations
