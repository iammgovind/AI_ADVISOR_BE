# Module Scope: Investment Tracking

## Purpose
This module tracks a user’s investments and monitors whether their portfolio is growing or declining.

## Business value
Users often hold investments but do not have a central, structured view of performance. This module gives them a clear portfolio snapshot.

## Included features
- Add investment holdings with symbol, type, quantity, buy price, and current price
- Track active and sold investments
- Group investments by type
- Calculate total invested value and current value
- Measure profit/loss percentage
- View holdings count and diversification status

## Supported investment categories
- stock
- mutual_fund
- sip
- etf
- crypto
- bond
- fd
- other

## Why it matters for the client demo
This shows the system is designed not only for spending management, but also for wealth building. It connects budgeting and savings decisions to investment outcomes.
