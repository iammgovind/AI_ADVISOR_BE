# Module Scope: Financial Advisory Agents

## Purpose
This module provides rule-based financial intelligence to assess risk, estimate savings capacity, and generate recommendations for better money decisions.

## Business value
The product is designed to do more than store data. It evaluates a user’s financial profile and recommends actions based on real signals like budget utilization, expense trends, goals, and portfolio health.

## Included features
- risk profile calculation
- savings plan estimation
- emergency fund recommendation
- goal feasibility analysis
- portfolio guidance
- overall financial health score
- multi-agent recommendation engine

## Agent categories
### 1. Risk agent
Evaluates the user’s financial behavior and scores risk based on:
- budget discipline
- investment pattern
- goal commitment
- portfolio diversity

### 2. Savings agent
Evaluates:
- monthly savings capacity
- savings rate percentage
- emergency fund target
- awareness of goal funding shortfalls
- investable surplus after goals and emergency needs

### 3. Multi-agent engine
Combines risk, savings, budget, and investment signals to generate:
- financial health score
- health status
- recommendations by priority

## Example outcome
A user may receive a recommendation such as: “Your budget is 90% utilized; improve savings rate and start a diversified SIP strategy.”

## Why it matters for the client demo
This is the intelligence layer that makes the project compelling. It shows the product can provide guidance, not just display numbers.
