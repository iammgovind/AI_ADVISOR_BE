# Module Scope: RAG and Document Intelligence

## Purpose
This module allows users to upload PDF documents and ask questions based on the content, creating a document-based financial assistant experience.

## Business value
Users often have policy documents, financial notes, insurance files, or research material. This module turns those documents into searchable knowledge for quick financial understanding.

## Included features
- Upload PDF files
- Store document metadata and chunk counts
- Ask questions about uploaded documents
- Retrieve relevant sources from the uploaded content
- Delete outdated or irrelevant documents

## Example use case
A user uploads a mutual fund brochure or financial policy document. They ask, “What are the tax implications?” and the system answers using the uploaded document as context.

## Why it matters for the client demo
This adds an AI-powered advisory layer beyond standard personal finance tracking and shows the product can evolve into a knowledge-rich assistant.
