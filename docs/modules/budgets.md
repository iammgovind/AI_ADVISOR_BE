# Module Scope: Budget Management

## Purpose
This module helps users set spending limits for each category and monitor whether they are staying within those limits.

## Business value
Budgets give users spending discipline. This module turns financial intent into measurable control.

## Included features
- Create category-based monthly budgets
- Associate budget limits with year and month
- Track actual spending against target
- Calculate remaining amount and utilization percentage
- Raise alerts when spending is near or beyond limits

## Example use case
A user sets a housing budget of ₹25,000 and a food budget of ₹8,000 for the month. The system tracks actual spending and warns when they are trending over budget.

## Why it matters for the client demo
Budgets are the bridge between raw expenses and smart financial decisions. They show the product is about planning and control, not only record keeping.
